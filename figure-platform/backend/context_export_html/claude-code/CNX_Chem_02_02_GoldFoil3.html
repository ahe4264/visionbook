Nuclear size
A bigger, more concentrated nucleus is a bigger target, so the chance of a large deflection grows roughly as R2. In a real gold atom the nucleus radius is about 1/25 000 of the atom — which is why Rutherford saw only ~1 in 20 000 α particles come back.
