1D convolution — multiple channels
Every value in H′ is a weighted sum over all 6 input channels inside the grey receptive-field box, plus a bias, then a ReLU.
The input never changes — only the weight tensor Ω does. Watch the cube colours swap: each output channel owns its own complete set of weights.
Click a circle in H′ to pick which output unit is being computed — the grey box in H jumps to the inputs that feed it. Hover the cubes of Ω or the box for details.
