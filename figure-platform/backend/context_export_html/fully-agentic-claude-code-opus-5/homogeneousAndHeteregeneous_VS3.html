Heterogeneous (2D) and homogeneous (projective) coordinates

A point (x, y) of the ordinary Euclidean plane is embedded in a three-dimensional space with an extra axis w as the canonical point (x, y, 1) on the plane w = 1. Every non-zero scalar multiple (λx, λy, λ) lies on the same ray through the origin and denotes the same 2D point — scale is irrelevant. Drag the red points, or use the sliders.

The whole dashed ray through the origin is one projective point, so a homogeneous vector carries no scale information. That is exactly what lets projective maps (homographies) — which include perspective projection and are not affine in 2D — be written as a single 3 × 3 matrix multiplication. Directions with w → 0 are rays parallel to the w = 1 plane: the points at infinity, which have no heterogeneous counterpart.
