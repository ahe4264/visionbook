From a 3D scene point to a pixel: the pinhole camera and its sensor

A scene point P = (Xc, Yc, Zc) is projected through the camera centre onto the virtual image plane at Zc = f, and lands inverted on the physical sensor at Zc = −f, where it is sampled by an M×N grid of finite-sized pixels. Everything drawn here is computed from the real projection equations.

Drag the point P anywhere in the figure (it moves in the plane Zc = const). Use depth to push it along the optical axis. The cyan dot is the exact projection; the orange cell is the pixel it is quantised into. Indices (n, m) are defined on the virtual image plane, so the stored image is upright; on the physical sensor the very same pixels sit rotated by 180°, which is why the picture on the grid is inverted.
