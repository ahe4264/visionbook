What the loss measures

Training data (dots), the line for the current φ (orange) and the best-fit line (dashed). Red sticks are the residuals; L[φ] is the sum of their squared lengths. Moving φ away from the minimum lengthens the sticks and climbs the bowl.

a) The loss surface over the two parameters, rendered as a 3-D mesh. b) The same function seen from above as a heat map with iso-loss contours; the contours are ellipses because the loss is exactly quadratic in φ. Both panels show the same three example parameter settings. Because the Hessian 2·[[N, Σxi], [Σxi, Σxi2]] is positive definite, the bowl is strictly convex: every downhill path ends at the single global minimum, marked by the white cross. The valley is elongated along the direction in which raising the intercept is compensated by lowering the slope — a shallow direction that makes plain gradient descent slow, and a large step size unstable.
