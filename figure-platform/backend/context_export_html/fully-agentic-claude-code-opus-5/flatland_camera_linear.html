Flatland: a 1-D pinhole camera as a linear system

A flatland scene is a row of 13 patches with light intensities (albedos) ℓw[0…12] at a fixed depth. An occluder with a pinhole sits between the scene and a 13-element sensor ℓs. Because every ray must pass through the single hole, the image lands reversed and scaled by the magnification m = ds/dw. The whole camera is then just a matrix: ℓs = A ℓw.

Click a scene patch to fire its ray fan  ·  drag up / down inside the scene bar to set patch brightness (drag sideways to paint several)  ·  the sensor bar is computed, never drawn by hand.

The camera matrix A

ℓs = A ℓw

How the geometry is computed. The pinhole sits at the occluder plane. A scene point xw sending a ray through an aperture point a lands at xs = a + (a − xw) m, with m = ds/dw = . Every ray, every arrowhead and the sensor bar width come from that one relation, so the sensor line is exactly m times as long as the scene line and is left–right reversed.

Why it is linear. Element i of the sensor collects the light of the scene patches whose images overlap it: ℓs[i] = Σj A[i,j] ℓw[j]. Each entry A[i,j] is the fraction of the rays reaching element i that came from patch j; it is obtained here by integrating over the sensor element and over the aperture. For an ideal pinhole A is a scaled reversal (anti-identity) matrix; widening the aperture turns it into a band — the same scene, blurred, and still a linear map.
