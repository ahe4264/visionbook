The logistic sigmoid sig[z]

A smooth, bounded, monotonic squashing function that maps any real number to the open interval (0, 1) — so its output can be read as a probability.

Drag the orange dot anywhere along the curve (or click in the plot to jump it there); drag the small grey arrow on the probability axis to move the threshold line. Either slider works too, and arrow keys nudge the focused slider.

Why it matters. The sigmoid is differentiable everywhere and its slope sig′(z) = sig(z) (1−sig(z)) is largest at z = 0, where the output is exactly 0.5. Far from the origin the curve flattens against its asymptotes 0 and 1 — the function saturates, and the gradient nearly vanishes. Choosing a threshold t on the probability axis is equivalent to choosing a cut point z* = ln[t/(1−t)] on the score axis, which is exactly how a logistic classifier turns a score into a decision.
