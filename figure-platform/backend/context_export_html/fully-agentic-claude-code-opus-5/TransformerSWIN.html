Hierarchical windowed self-attention in the Swin Transformer

Self-attention is computed only between patches that fall inside the same window. Shrinking the windows makes attention cheap but local; shifting the window grid by half a window between successive layers lets information leak across window borders — without ever paying the quadratic cost of global attention.

What the figure shows

a) the input image, tokenised into a 16×16 grid of patches. b–f) the same token grid cut into attention windows: 4×4 windows (b) and the same grid displaced by half a window (c); 2×2 windows (d) and their offset variant (e); and the degenerate 1×1 case (f), which is ordinary global self-attention over all 256 tokens.

Attention cost is Σw |w|² summed over windows, so splitting the 256 tokens into 16 windows of 16 tokens costs 4 096 pairs instead of 65 536 — a 16× saving, but every token is then blind to everything outside its own window. A Swin block therefore uses the regular partition in layer ℓ and the shifted partition in layer ℓ+1: two patches separated by a boundary in one layer share a window in the next, so the receptive field grows layer by layer while attention stays linear in the number of tokens.

Note that the shifted partition is genuinely finer at the borders: displacing a grid of M×M windows by ⌊M/2⌋ produces partial windows along all four edges (panels c and e), which is why the shifted layer has more — and smaller — windows than the regular one.
