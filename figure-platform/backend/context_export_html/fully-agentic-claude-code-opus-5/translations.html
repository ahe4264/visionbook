Translation in the plane, and the composition of two translations

A translation slides every point of the square by the same vector — it does not rotate or resize it. Drag the arrow tips (or the orange squares) to change the vectors. Composing translation t with translation s gives the single translation t + s, which is why translations become a product of matrices in homogeneous coordinates.

In homogeneous coordinates a point is (x, y, 1). The extra row and column let the constant shift t ride in the last column, so a translation — which is not linear in 2 D — becomes an ordinary 3×3 matrix product.

Applying t first and then s means multiplying T(s)·T(t); only the last column adds up, so the result is the single translation by t + s. The order makes no difference — translations commute, and the two red arrows plus the resultant always close the same triangle.

Squares are the same size and orientation in every position: a translation is a rigid motion with no rotation and no scaling. The black axes mark the fixed xy‑frame; the original square is centred on the origin.
