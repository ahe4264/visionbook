1D convolution with multiple channels

The input layer H is a volume of hidden units indexed by height, width and channel. A 1D convolution runs along the width axis only: at every position it takes a window of K width-taps across all input channels, multiplies it by a weight slice Ω (⊗), adds a bias (⊕), and writes one number into one channel of the output layer H′. The same filter is reused at every width position and every height row.

H′[h, w, c′]  =  β[c′]  +  Σc=1..C Σk=1..K  Ω[c′, c, k] · H[h, w+k−1, c]
