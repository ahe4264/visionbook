Reprojection error — the objective function of camera calibration

Three scene points P1, P2, P3 project through the real camera onto its image plane, giving the observed image points pi. Projecting the same 3D points with the estimated camera model (K̂, R̂, T̂) gives the predicted points p′i. The red segment between each pair is the 2D residual; calibration/bundle adjustment minimises the sum of their squared lengths.

Drag: an observed point pi (move the measurement) · a predicted point p′i (shifts the estimated principal point — all three move together) · a 3D point Pi · empty space to orbit the view.
