Model capacity and the smoothness of the fitted function

A shallow network with one hidden layer is fitted to the same six training points in every panel. Every fit passes through all six points, yet what happens between them depends sharply on how many hidden units the network has: few units force wild excursions, many units give a smooth curve that tracks the true function.
