The washer method — revolving the region under y = f(x) about the line y = c

Region R lies between the curve and the x-axis on [0, 2]. Revolving it about the horizontal line y = c sweeps out a solid whose cross-section at each x is a washer: outer radius R(x) = |f(x) − c|, inner radius r = |0 − c|.
