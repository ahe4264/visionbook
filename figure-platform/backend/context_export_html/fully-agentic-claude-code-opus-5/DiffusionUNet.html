The U‑Net noise predictor εθ(xt, t) of a diffusion model

A diffusion model denoises by repeatedly asking one network the same question: “given this noisy image xt and the timestep t, which part of it is noise?” The network is a U‑Net: an encoder that shrinks the image while growing the channel count, a bottleneck, and a decoder that mirrors the encoder back up to full resolution. Concatenate arrows carry each encoder feature map across to the decoder stage of the same spatial size, so fine detail lost by downsampling is restored. The circled t at the bottom is turned into a time embedding γ(t) that is injected into every residual block, which is what lets a single set of weights serve all 1000 noise levels.

How to read the volumes. Every box is a real feature-map tensor drawn with an oblique projection (depth axis at 31.8°): its height is proportional to the spatial resolution S, its width (the pale front face) is proportional to the channel count C, and its depth (the dark face) is the second spatial axis, drawn compressed (∝√S) so that the 8×8 maps stay visible. Hover any volume for its exact shape and cost. Halving the resolution doubles or keeps the channels, so the tensors get short and wide as you go deeper — the classic U‑Net trade of space for semantics.
