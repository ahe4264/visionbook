Reconstruction of a continuous signal from its samples

The sample train (left) is convolved with the sinc interpolation kernel (middle); the result (right) is the sum of one scaled, shifted sinc per sample — a continuous curve that passes exactly through every sample tip.

Sampling interval  Ts = 1.00 dense sampling ←    → past the Nyquist limit

samples x(nTs) sinc kernel / scaled copies reconstruction x̂(t) = sum of the copies original x(t)

x̂(t)  =  ∑n  x(nTs)  sinc ( (t − nTs) / Ts ),    sinc(u) = sin(πu) / (πu)

Click any blue arrow in the right-hand panel to remove that sample's sinc copy from the sum: the red curve immediately stops passing through that sample, showing that reconstruction is a linear superposition in which every sample carries its own interpolation function. The test signal is exactly band-limited to fmax = 0.5 (time unit T₀ = 1), so the Nyquist condition here is Ts ≤ 1.
