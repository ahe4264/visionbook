Line integral of a scalar function: the partition that defines it

A wire follows a space curve C from P to Q with density f(x, y, z). Split C into n arcs of length Δsk; on each one the density is nearly constant, so the mass of the kth arc is ΔMk ≈ f(P*k) Δsk. Adding these gives a Riemann sum whose limit is the line integral ∫C f ds.
