Deep residual network (ResNet v2): the whole pipeline, and what is inside one ResBlock

Tensors flow left → right. Each cuboid is a feature tensor: its height encodes the spatial size H×W and its length encodes the channel count C (both on a compressed power scale so 3 … 2048 channels fit on one page). Every stage halves the spatial resolution and doubles the depth. Why it works. A residual block computes y = x + F(x). The skip path carries x straight to the ⊕, so however many blocks are stacked, there is always an uninterrupted route from the loss back to the early layers: ∂y/∂x = I + ∂F/∂x, which cannot vanish. The block body is a bottleneck: a 1×1 conv squeezes C channels down to C/4, a 3×3 conv does the expensive spatial mixing in that cheap space, and a second 1×1 conv expands back to C — which is what makes 100+ block networks affordable. The ordering shown (BN → ReLU → Conv, three times) is the pre-activation variant, ResNet v2, in which the skip path is a completely clean identity.
