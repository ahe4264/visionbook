Area under a curve as a limit of rectangle sums

The region under y = f(x) from x = a to x = b is approximated by inscribed rectangles — on each subinterval the rectangle height is the smallest value of f there, so every rectangle fits under the curve. Increasing the number of rectangles n squeezes the approximation up toward the true area: A = limn→∞ Σ f(xi*) Δx.
