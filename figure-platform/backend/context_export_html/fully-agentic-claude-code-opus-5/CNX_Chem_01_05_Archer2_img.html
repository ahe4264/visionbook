Precision and accuracy are two different things

Four archers each shoot four arrows at the same target. Precision is how tightly the shots cluster with one another; accuracy is how close they land to the true centre. Every number below is measured from the dots themselves — move a dot, or add one, and the verdict is recomputed.

Archer Y — shots flung all around the target: neither. Note that Y’s shots happen to average close to the centre, yet not one arrow is near it — averaging away random error is luck, not accuracy. Archer Z — two shots on the rings, two far away: neither precise nor accurate.

How the three numbers are computed

Let the true centre be the origin and let the n shots be at positions pₖ, measured in units of the outer target radius R. The centroid (the archer’s mean shot) is p̄ = (1/n) Σ pₖ. Then:

  • Typical miss e = √( (1/n) Σ |pₖ|² ) — the root-mean-square distance of the shots from the true centre. This is the total error.
  • Bias b = |p̄| — how far the whole group sits from the centre. This is the systematic error.
  • Scatter s = √( (1/n) Σ |pₖ − p̄|² ) — the spread about the group’s own centroid (the 2-D standard deviation). This is the random error.

These three are not independent — expanding the squares gives the exact identity e² = b² + s², which is the whole lesson in one line: total error comes from a systematic part and a random part. Precision only controls s; you can drive s to zero (Archer X) and still have an enormous e, because nothing about repeating a measurement removes b.

The verdicts use geometric thresholds: precise when s ≤ 0.30 R (the group would fit inside a bullseye-sized circle) and accurate when e ≤ 0.50 R (a typical shot lands within the inner half of the target radius).
