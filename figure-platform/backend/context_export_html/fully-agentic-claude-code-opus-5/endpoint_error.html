Endpoint error of an optical-flow estimate

The ground-truth flow vector (u, v) and the predicted flow vector (û, v̂) leave the same pixel. The red segment joining their tips is the endpoint error — the Euclidean distance between the two endpoints. Drag either arrowhead to see how direction and length errors both feed into it.

Error metric

EPE = 0.00 px
EPE = √[(û−u)² + (v̂−v)²] — the length of the red segment. Zero only if the prediction matches in both direction and magnitude.
θ = 0.0°
θ = arccos[(u·û + v·v̂) / (‖(u,v)‖‖(û,v̂)‖)] — the blue arc at the origin. Unchanged if the prediction is scaled along its own direction, so it is blind to magnitude error.
