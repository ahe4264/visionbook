Continuity of sin and cos at a point c

As x → c, the point P(cos x, sin x) travels along the unit circle to Q(cos c, sin c) — so both coordinates converge.

As x approaches c the point P approaches the point Q.

Each coordinate gap is squeezed between 0 and the arc length |x − c|, which the slider drives to 0 from either side. Hence limx→c sin x = sin c and limx→c cos x = cos c: sine and cosine are continuous at every point c.
