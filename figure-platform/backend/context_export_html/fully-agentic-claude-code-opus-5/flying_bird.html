A bird flying away: the vanishing point (focus of expansion)

A static pinhole camera at O watches a bird translate along a straight line at constant 3‑D velocity V. The red 3‑D arrows are all the same length — the bird never slows down. Yet its image creeps toward one fixed spot on the image plane, the vanishing point of the direction V, and its image velocity dies away to zero.

The geometry behind it

P(t) = P0 + t V  ·  perspective projection p = f (X, Y) / Z
p(t)  ⟶  f (Vx, Vy) / Vz  as t → ∞  — the vanishing point
v = d p/dt = f (VxZ − X Vz, VyZ − Y Vz) / Z²

The numerator is constant along the path, so the image speed falls off like 1/Z²: the bird's picture slows to a halt at the vanishing point even though the bird itself never changes speed. Because the vanishing point depends only on Vx:Vy:Vz, every object translating in that same direction shares it — for a camera moving forward through a static world this point is the focus of expansion.
