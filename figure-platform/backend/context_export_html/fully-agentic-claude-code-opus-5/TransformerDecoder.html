Autoregressive transformer decoder

Seven token positions run left to right through word embeddings, a stack of K masked-attention layers, and a shared Linear + softmax head that emits a probability distribution over the vocabulary at every position. The lower-triangular line pattern is the causal mask: position j may read positions i ≤ j only, so each output row predicts the next token without ever seeing it.

K = 6
