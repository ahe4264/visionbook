What to look for. The bowl is long and narrow because the intercept and the slope are strongly correlated (the inputs xi are all positive, so raising the slope can be partly undone by lowering the intercept). Steepest descent always steps perpendicular to the contours, so from a far-away start it first dives across the valley and then crawls slowly along its floor. Push α above about 0.040 and the steps over-shoot the narrow direction and the path diverges.
