The StyleGAN generator: style in, noise in

Latent z is mapped to an intermediate code w, from which three affine transforms produce styles y1, y2, y3. Each style is a per-channel scale and offset applied by adaptive instance normalisation. Independent single-channel noise maps, scaled by ψ, are broadcast over all 512 channels and added just before each normalisation. Everything drawn below — noise maps, style vectors, feature maps and the output image — is actually computed.
