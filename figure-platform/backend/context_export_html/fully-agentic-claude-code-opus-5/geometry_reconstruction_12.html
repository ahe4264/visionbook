Two-view geometry: reconstructing a 3D point from a moving camera

The image point p in the target frame ℓ2 is back-projected to a 3D point P = zK−1p; the same physical point written in the reference frame is P′ = MP = RP + T, and it images at p′ = KP′ in ℓ1. Drag p, drag P along its ray, move the relative pose (R, T), or drag the background to orbit the view.
