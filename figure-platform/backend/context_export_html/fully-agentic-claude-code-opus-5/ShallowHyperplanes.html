Neurons as hyperplanes: 1D, 2D and 3D input spaces

A single neuron computes the pre-activation z = w·x + b and fires where z > 0. The decision boundary {x : w·x + b = 0} is a hyperplane — always one dimension lower than the input space: a point in 1D, a line in 2D, a plane in 3D. The weight vector w is the normal to that hyperplane, so moving one weight component tilts it; the bias slides it off the origin.

a)  One input

z = w1x1 + b

The boundary sits at x1 = −b / w1 (teal tick). Sign of w1 decides which side is positive.

b)  Two inputs

z(i) = w1x1 + w2x2 + b

c)  Three inputs

z(i) = w1x1 + w2x2 + w3x3 + b

Input point x  —  drag it in any panel, or use the sliders

In panel c, plain dragging moves x1 and x2; hold Shift and drag vertically to move along x3. Hidden parts of the axes and of the point are drawn dashed.
