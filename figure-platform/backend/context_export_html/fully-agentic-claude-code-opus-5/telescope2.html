Galilean telescope — angular magnification f1/f2

A converging objective (lens 1) and a diverging eyepiece (lens 2). Parallel light arriving at angle δi is brought to a point a distance d = f1 tan δi off axis in the objective's focal plane; because that plane is also the eyepiece's focal plane, the light leaves as a parallel bundle at the larger angle δo, with tan δo = d/f2.

Try: drag the mauve handle at the left end of the rays to tilt the incoming starlight — the exit angle grows by the same factor f₁/f₂ whatever δᵢ is. Raise f₁ or shrink f₂ and the offset d or the lever arm f₂ changes, so the magnification changes. Drag lens 2 off the afocal spacing and the exit bundle stops being parallel: the telescope no longer images objects at infinity to infinity, and the magnification is no longer defined by f₁/f₂ alone.
