Encoding a graph for a neural network: A, X and E

A graph with node and edge attributes is stored as three arrays: the adjacency matrix A (who is connected to whom), the node data matrix X (one feature column per node) and the edge data matrix E (one feature column per edge). Click a node or an edge in panel (a) — or any cell in A, X or E — to see the same object in every representation.

Focus panel

The adjacency matrix is computed from the edge list, so it is symmetric with a zero diagonal by construction (undirected graph, no self-loops). The feature values in X and E are fixed pseudo-random numbers in [0,1]; the coloured stack drawn beside each node and each edge in panel (a) is that object's column in X or E.
