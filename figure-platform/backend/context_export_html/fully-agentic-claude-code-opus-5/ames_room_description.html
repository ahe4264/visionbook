The Ames room: one viewpoint, two rooms

A top‑down floor plan. The actual room is a trapezoid, but seen through the pinhole it is indistinguishable from a square room. Two physically identical objects sit in the two rear corners; because the left corner is genuinely much farther away it subtends a smaller visual angle, and a brain that assumes a rectangular room must conclude that the object there is smaller. The dashed circle is where — and how big — that object is judged to be.
