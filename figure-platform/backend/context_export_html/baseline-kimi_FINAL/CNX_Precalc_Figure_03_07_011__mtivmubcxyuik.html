f(x) = (x+1)(x−1) ⁄ (x+1)(x−3)
= (x−1)/(x−3),  x ≠ −1
The cancelled factor (x+1) means only the single value f(−1) is missing: g(−1) = 0.5 would fill the hole — that is why the break at x = −1 is “removable”. The factor (x−3) never cancels, so x = 3 stays a vertical asymptote.
